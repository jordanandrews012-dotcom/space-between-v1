# The Space Between

A three-paper policy series on Ontario's continuous authority gap in hospital mental health crisis response, and the case for applying the province's existing Special Constable designation to the hospital environment.

**Author:** Jordan Andrews &mdash; Protection Services Officer, Queensway Carleton Hospital, Ottawa

**Published:** April 2026
